Memory Match is the classic pairs game. Flip two cards at a time and remember where each picture is. Match every pair in as few moves as you can.

How to play Memory Match

  • Flip two cards.
  • If they match they stay face up.
  • If not, they turn back over, so remember them.
  • Match all pairs to win.

Controls

  • Click or tap a card to flip it

Features

  • Good for kids and adults
  • Trains short-term memory
  • Mouse and touch friendly
  • Free to play, no download, no account
  • Runs in any modern browser, including school Chromebooks
